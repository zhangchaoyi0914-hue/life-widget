# Life Widget for Windows

一个极简的 Windows 桌面时间进度小组件：用圆点矩阵把时间的流逝可视化 ——
**今天 / 本周 / 本月 / 今年 / 人生**，深色点 = 已过去，橙点 = 当前，浅灰点 = 未到来。
美术风格参考 iOS 应用 [Life Widget](https://www.lifewidget.app/) 的主屏幕小组件。

*A minimalist desktop widget for Windows that visualizes the passage of time —
today / week / month / year / life — as dot grids, rings, bars and arcs.*

## 界面预览

- 圆角卡片上竖向堆叠任意勾选的进度块，卡片高度自适应
- 同一进度有多种**表现形式**，单击进度块循环切换：

| 进度块 | 表现形式 |
| --- | --- |
| 今天 | 24 小时点阵 → 60 分钟点阵 → 时钟圆环 → 进度条 |
| 本周 | 7 天点阵 → 168 小时点阵 → 大"周六" → 进度条 |
| 本月 | 普通点阵 → 日历式(带星期表头) → 进度条 |
| 今年 | 周数点阵 → 365 天点阵 → 进度条 |
| 人生 | 年份点阵 → 月份点阵 → 100 格(每格 1%) → 圆环 → 微笑弧线 → 进度条 |

- 另有独立的**圆环组合**块(今日/本周/本月/今年四个圆环一排)
- 浅色 / 深色主题，圆形 / 方形圆点(带圆角)，所有图形 3 倍超采样抗锯齿渲染
- 点阵级联淡入动画，当前橙点呼吸动画

## 运行环境

- Windows 10 / 11
- Python 3.8+(自带 tkinter)
- [Pillow](https://pypi.org/project/Pillow/):`pip install pillow`

## 启动

```bat
pip install pillow
```

- 双击 `启动小组件.vbs`(推荐,无控制台窗口)
- 或命令行:`pythonw life_widget.py`

首次运行会弹出设置窗口,填写**出生日期**和**预期寿命**,并勾选想显示哪些进度。

## 操作

| 操作 | 方式 |
| --- | --- |
| 切换表现形式 | 单击该进度块的任意位置(右上角有 ⇄ 图标提示) |
| 移动位置 | 左键按住拖动(位置自动记住) |
| 打开菜单 | 右键点击小组件 |
| 退出 | 右键菜单 → 退出,或按 `Esc` |

右键菜单可切换**窗口置顶**和**开机自启**(写入注册表
`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`,随时可在菜单里关掉)。

## 设置项

- **出生日期 / 预期寿命** —— 用于计算"人生"进度
- **显示哪些进度** —— 今天 / 本周 / 本月 / 今年 / 人生 / 圆环组合,任意勾选(至少一个)
- **背景模式** —— 浅色 或 深色
- **圆点形状** —— 圆形 或 方形(带圆角)

所有设置(含每块当前形式、窗口位置)保存在同目录 `config.json`,退出后重开自动恢复。

## 文件说明

- `life_widget.py` —— 主程序
- `启动小组件.vbs` —— 双击启动器(自动查找 Python,无需配置路径)
- `config.json` —— 首次保存设置后自动生成(不会提交到仓库)

## 卸载

在右键菜单关闭"开机自启",然后删除本文件夹即可。
